## AI Use Disclosure

The current codebase originates from a series of legacy Jupyter notebooks developed by the authors in Bogotá during a research visit by GM to the Observatorio Nacional de Colombia in January 2026. OpenAI Codex was used to assist with portions of the subsequent code refactoring, mostly to reorganize and pipeline the existing code for production use. All scientific decisions (planning of the project, design of the research, pursue of results) and data-related work, including SMILES collection, model training, validation, and interpretation of results, were performed by the authors.
